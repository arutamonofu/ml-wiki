MSE loss (mean squared error) — функция потерь регрессии, измеряющая средний квадрат отклонения предсказаний от истинных значений. Применяется как гладкий критерий в градиентной оптимизации.

| Свойство       | Описание                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------ |
| Тип задачи     | [[regression\|Регрессия]]                                                                        |
| Вход           | Векторы предсказаний $\mathbf{\hat{y}} \in \mathbb{R}^n$ и ответов $\mathbf{y} \in \mathbb{R}^n$ |
| Выход          | Скаляр $L_{\text{MSE}} \in [0, +\infty)$                                                         |
| Гиперпараметры | Отсутствуют (во фреймворках: агрегация `mean` / `sum`)                                           |
| Свойства       | Выпуклая, непрерывно [[дифференцирование\|дифференцируемая]], чувствительна к выбросам           |

Скалярная форма:

$$L_{\text{MSE}} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

Векторная форма:

$$L_{\text{MSE}} = \frac{1}{n} \|\mathbf{y} - \mathbf{\hat{y}}\|_2^2 = \frac{1}{n} (\mathbf{y} - \mathbf{\hat{y}})^T (\mathbf{y} - \mathbf{\hat{y}})$$

Градиент по вектору предсказаний:

$$\nabla_{\mathbf{\hat{y}}} L_{\text{MSE}} = \frac{2}{n} (\mathbf{\hat{y}} - \mathbf{y})$$

## Достоинства и недостатки

Достоинства:

- Предсказуемая оптимизация: выпуклость и гладкость обеспечивают затухание градиента у оптимума;
- Строгая интерпретируемость: соответствует оценке условного математического ожидания;
- Стабильность сходимости: устойчивый расчет градиентов без численных скачков;
- Низкая вычислительная сложность: не содержит гиперпараметров и легко дифференцируется.

Недостатки:

- Чувствительность к [[выбросы|выбросам]]: квадратичный штраф создает избыточные градиенты на аномалиях;
- Ограниченность применения: не подходит для распределений с тяжелыми хвостами.
