## Свойства

| Свойство               | Значение                                                                                                                                                                                                                            |
| :--------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тип данных             | Две количественные переменные                                                                                                                                                                                                       |
| Нулевая гипотеза       | Коэффициент корреляции Пирсона в генеральной совокупности ($\rho$) равен нулю. ($H_0: \rho = 0$)                                                                                                                                    |
| Распределение критерия | [[Распределение Стьюдента]]                                                                                                                                                                                                         |
| Условия                | - Данные являются случайной выборкой.<br>- Обе переменные распределены нормально (или размер выборки $n$ достаточно велик, обычно $n > 30$).<br>- Линейность корреляции.<br>- Гомоскедастичность (однородность дисперсии остатков). |
| Обозначение            | $t$                                                                                                                                                                                                                                 |

## Вычисление

$$r \sqrt{\frac{n-2}{1-r^2}}$$

$r$ - выборочный коэффициент корреляции Пирсона,
$n$ - количество пар наблюдений.

Число степеней свободы:

$$df = n - 2$$

## Пример

Компания хочет выяснить, существует ли статистически значимая линейная связь между стажем работы маркетолога (в годах) и среднемесячным ростом продаж (в %). Была собрана выборка из 20 маркетологов. По результатам сбора данных был рассчитан выборочный коэффициент корреляции Пирсона $r = 0.452$.

Вопрос: можно ли на уровне значимости $\alpha = 0.05$ утверждать, что существует значимая линейная корреляция между стажем работы маркетолога и ростом продаж?

Решение:

1. Сформулируем $H_0$:
	- Коэффициент корреляции в генеральной совокупности равен нулю, т.е. нет линейной связи).

2. Рассчитаем $t$:
    *   $t = 0.452 \sqrt{\frac{20-2}{1-(0.452)^2}} \approx 2.150$

3. Рассчитаем $df$:
    *   $df = 20 - 2 = 18$

4. Найдём $p$-значение:
    *   Для $t$ и $df$ (двусторонний тест), $p$-значение составляет примерно $0.045$.

5. Сравним $p$ и $\alpha$:
    *   $0.045 < 0.05$.

Вывод: на уровне значимости $0.05$ существует линейная корреляция между стажем работы маркетолога и ростом продаж.
