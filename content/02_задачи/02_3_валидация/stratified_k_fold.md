---
title: Stratified K-Fold
---
Stratified K-Fold — метод кросс-валидации с разделением выборки на $K$ фолдов и сохранением соотношения классов.

Алгоритм:

1. Группировка объектов по меткам классов. Для $N = 6$ объектов с классами 0 и 1: $C_0 = [x_1, x_2, x_3, x_4]$ и $C_1 = [x_5, x_6]$.
2. Пропорциональное разделение каждого класса на $K$ блоков. При $K = 2$: $B_1 = [x_1, x_2, x_5]$, $B_2 = [x_3, x_4, x_6]$.
3. Формирование выборок для итерации $i = 1$: $X_{\text{val}} = B_1 = [x_1, x_2, x_5]$, $X_{\text{train}} = B_2 = [x_3, x_4, x_6]$.
4. Обучение модели на $X_{\text{train}}$ и расчет локальной метрики $E_1$ на проверочном множестве $X_{\text{val}}$.
5. Повторение итераций $K$ раз со сменой проверочного блока и усреднение: $\text{Score} = \frac{1}{K} \sum_{i=1}^{K} E_i$.

Особенности:

- Применяемость: задачи классификации с дисбалансом классов.
- Ключевой риск: утечки данных при наличии временных или групповых связей.
- Вычислительная сложность: умеренная сложность из-за $K$-кратного обучения, итерации параллелятся.
- Ограничения: $K \le N$, требует дискретизации целевой переменной в регрессии.
