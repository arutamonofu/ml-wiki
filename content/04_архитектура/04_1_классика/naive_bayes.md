Наивный байесовский классификатор вычисляет наиболее вероятный класс объекта по [[теорема_байеса|теореме Байеса]] в предположении о независимости признаков.

| Свойство     | Описание                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| Задача       | [[classification\|Классификация]] (бинарная, многоклассовая)                                             |
| Тип обучения | С учителем                                                                                               |
| Вход         | Матрица признаков $\mathbf{X} \in \mathbb{R}^{n \times d}$                                               |
| Выход        | Классы $\hat{\boldsymbol{y}} \in \{1, \dots, K\}^n$ или вероятности $\mathbf{P} \in [0, 1]^{n \times K}$ |

> [!math]+ Математика
> Оценка класса объекта $\boldsymbol{x}_i$:
>
> $$y_i = \operatorname{argmax}_{k \in \{1, \dots, K\}} \left( P(y = k) \prod_{j=1}^{d} P(x_{i,j} \mid y = k) \right)$$
>
> Апостериорная [[вероятность]] класса $k$:
>
> $$P(y = k \mid \boldsymbol{x}_i) = \frac{P(y = k) \prod_{j=1}^{d} P(x_{i,j} \mid y = k)}{\sum_{l=1}^{K} P(y = l) \prod_{j=1}^{d} P(x_{i,j} \mid y = l)}$$
>
> Обозначения:
>
> - $\mathbf{X} \in \mathbb{R}^{n \times d}$ — матрица из $n$ объектов и $d$ признаков.
>
> - $P(y = k)$ — априорная вероятность класса $k$.
>
> - $P(x_{i,j} \mid y = k)$ / $p(x_{i,j} \mid y = k)$ — вероятность или плотность $j$-го признака для класса $k$.
>
> - $K$ — число классов.
>
> - Условная независимость: $P(\boldsymbol{x}_i \mid y = k) = \prod_{j=1}^{d} P(x_{i,j} \mid y = k)$.

## Обучение

Оценка параметров априорных $P(y = k)$ и условных $P(x_j \mid y = k)$ [[03_теория/03_4_статистика/распределения/index|распределений]] методом максимального правдоподобия.

Для дискретных признаков со сглаживанием Лапласа ($\alpha \ge 0$):

$$P(x_j = v \mid y = k) = \frac{\sum_{i=1}^{n} \mathbb{I}[y_i = k \land x_{i,j} = v] + \alpha}{\sum_{i=1}^{n} \mathbb{I}[y_i = k] + |V_j| \alpha}$$

Для непрерывных признаков с гауссовской плотностью $p(x_j \mid y = k)$:

$$p(x_j \mid y = k) = \frac{1}{\sqrt{2\pi\sigma_{k,j}^2}} \exp\left(-\frac{(x_j - \mu_{k,j})^2}{2\sigma_{k,j}^2}\right)$$

| Свойство                   | Описание                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| Обучаемые параметры        | $P(y=k)$, оценки $P(x_j \mid y=k)$ или $\mu_{k,j}, \sigma_{k,j}^2$                                   |
| Гиперпараметры             | Сглаживание $\alpha$, тип распределения                                                              |
| Временная сложность        | $\mathcal{O}(n d)$                                                                                   |
| Пространственная сложность | $\mathcal{O}(K d)$ для гауссовского; $\mathcal{O}\left(K \sum_{j=1}^dV_j\right)$ для категориального |

---

## Инференс

Классификация объекта $\boldsymbol{x}_\text{new} \in \mathbb{R}^d$ в логарифмической форме:

$$\hat{y} = \operatorname{argmax}_{k \in \{1, \dots, K\}} \left( \ln P(y = k) + \sum_{j=1}^{d} \ln P(x_{j, \text{new}} \mid y = k) \right)$$

| Свойство                   | Описание                                                           |
| -------------------------- | ------------------------------------------------------------------ |
| Временная сложность        | $\mathcal{O}(K d)$ на объект                                       |
| Пространственная сложность | $\mathcal{O}(K d)$ или $\mathcal{O}\left(K \sum_{j=1}^dV_j\right)$ |

---

## Достоинства и недостатки

Достоинства:

- Высокая скорость обучения и инференса при низкой требуемой памяти;
- Простая интерпретируемость за счет явного расчета вероятностей;
- Устойчивость к переобучению на малых выборках.

Недостатки и ограничения:

- Неспособность моделировать корреляции и взаимодействия признаков;
- Искажение оценок вероятностей при нарушении условия независимости;
- Чувствительность к [[выбросы|выбросам]] при работе с непрерывными признаками.
