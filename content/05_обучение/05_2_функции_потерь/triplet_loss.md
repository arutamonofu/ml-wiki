---
title: Triplet loss
---
Triplet Loss — функция потерь в метрическом обучении (metric learning), оценивающая относительные [[норма_вектора|расстояния]] между эмбеддингами. Сближает векторы похожих объектов и отдаляет векторы разных.

| Свойство | Описание |
| --- | --- |
| Тип задачи | Обучение представлениям |
| Вход | Эмбеддинги: якорь $\mathbf{a}_i \in \mathbb{R}^d$, позитивный $\mathbf{p}_i \in \mathbb{R}^d$, негативный $\mathbf{n}_i \in \mathbb{R}^d$ |
| Выход | Скаляр $L_{\text{Triplet}} \in [0, +\infty)$ |
| Гиперпараметры | Зазор разделения $m > 0$ (margin) |
| Свойства | Формирует метрическое пространство, требует майнинга триплетов |

Математическое определение в скалярной форме:

$$L_{\text{Triplet}} = \frac{1}{n} \sum_{i=1}^{n} \max\left(0, \|\mathbf{a}_i - \mathbf{p}_i\|_2^2 - \|\mathbf{a}_i - \mathbf{n}_i\|_2^2 + m\right)$$

Векторная форма (через срезочную функцию $[x]_+ = \max(0, x)$):

$$L_{\text{Triplet}} = \frac{1}{n} \mathbf{1}^T \left[ \mathbf{d}_{\mathbf{a}, \mathbf{p}} - \mathbf{d}_{\mathbf{a}, \mathbf{n}} + m \mathbf{1} \right]_{+}$$

Градиенты активных триплетов (где значение под максимумом $> 0$):

$$\nabla_{\mathbf{a}_i} L_{\text{Triplet}} = \frac{2}{n} (\mathbf{n}_i - \mathbf{p}_i), \quad \nabla_{\mathbf{p}_i} L_{\text{Triplet}} = \frac{2}{n} (\mathbf{p}_i - \mathbf{a}_i), \quad \nabla_{\mathbf{n}_i} L_{\text{Triplet}} = \frac{2}{n} (\mathbf{a}_i - \mathbf{n}_i)$$

---

## Достоинства и недостатки

Достоинства:

- Геометрическая интерпретируемость: напрямую задает расстояния в пространстве эмбеддингов
- Адаптивность: позволяет сравнивать новые классы без переобучения модели
- Направленная оптимизация: явно задает минимальный зазор между классами

Недостатки и ограничения:

- Замедление сходимости: простые триплеты дают нулевые градиенты
- Чувствительность к шуму: неверная разметка и крайние значения margin срывают оптимизацию
- Высокая вычислительная сложность: кубический рост комбинаций $\mathcal{O}(N^3)$ требует майнинга триплетов
