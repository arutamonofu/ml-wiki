MAE loss (mean absolute error) — функция потерь регрессии, оценивающая средний модуль отклонения предсказаний от истинных значений. Используется при градиентной оптимизации.

| Свойство       | Описание                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Тип задачи     | [[regression\|Регрессия]]                                                                                                             |
| Вход           | Предсказания $\mathbf{\hat{y}} \in \mathbb{R}^n$, ответы $\mathbf{y} \in \mathbb{R}^n$                                                |
| Выход          | Скаляр $L_{\text{MAE}} \in [0, +\infty)$                                                                                              |
| Гиперпараметры | Нет (во фреймворках настраивается агрегация: `mean` / `sum`)                                                                          |
| Особенности    | [[дифференцирование\|Недифференцируемость]] при $\mathbf{\hat{y}} = \mathbf{y}$, устойчивость к выбросам, постоянный модуль градиента |

Математическое определение в скалярной форме:

$$L_{\text{MAE}} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

В векторной форме:

$$L_{\text{MAE}} = \frac{1}{n} \|\mathbf{y} - \mathbf{\hat{y}}\|_1$$

Градиент по вектору предсказаний:

$$\nabla_{\mathbf{\hat{y}}} L_{\text{MAE}} = \frac{1}{n} \operatorname{sign}(\mathbf{\hat{y}} - \mathbf{y})$$

---

## Достоинства и недостатки

Достоинства:

- Устойчивость к выбросам: линейный штраф предотвращает взрыв градиентов
- Интерпретируемость: измеряется в единицах целевого признака и соответствует условной медиане
- Простота: не имеет гиперпараметров и не требует настройки

Недостатки:

- Осцилляции около минимума: недифференцируемость при $\mathbf{\hat{y}} = \mathbf{y}$ и постоянный модуль градиента затрудняют точную сходимость
- Зависимость от [[масштабирование|масштаба]]: затруднено сравнение значений на данных с разным масштабом
