Логистическая регрессия — линейная модель для оценки вероятности принадлежности объекта к классу с помощью сигмоиды.

| Свойство     | Описание                                                   |
| ------------ | ---------------------------------------------------------- |
| Задача       | [[classification\|Классификация]]                          |
| Тип обучения | С учителем                                                 |
| Вход         | Матрица признаков $\mathbf{X} \in \mathbb{R}^{n \times d}$ |
| Выход        | Вектор вероятностей $\boldsymbol{p} \in (0, 1)^n$          |

> [!math]+ Математика
> Модель $f: \mathbb{R}^{n \times d} \to (0, 1)^n$:
>
> $$\boldsymbol{p} = \sigma(\mathbf{X}\boldsymbol{w} + b\mathbf{1})$$
>
> Где:
>
> - $\mathbf{X} \in \mathbb{R}^{n \times d}$ — матрица признаков;
>
> - $\boldsymbol{w} \in \mathbb{R}^d$ — вектор весов;
>
> - $b \in \mathbb{R}$ — смещение;
>
> - $\mathbf{1} \in \mathbb{R}^n$ — единичный вектор;
>
> - $\sigma(z) = \frac{1}{1 + e^{-z}}$ — сигмоида (поэлементно).

---

## Обучение

Оптимизация параметров $\boldsymbol{w}$ и $b$ через минимизацию бинарной кросс-энтропии.

Методы: градиентный спуск, L-BFGS, метод Ньютона — Рафсона.

| Свойство | Описание |
| --- | --- |
| Обучаемые параметры | Веса $\boldsymbol{w} \in \mathbb{R}^d$, смещение $b \in \mathbb{R}$ |
| Гиперпараметры | Наличие смещения, функция потерь, оптимизатор, темп обучения, регуляризация |
| Временная сложность | $\mathcal{O}(n d e)$ — градиентные методы ($e$ эпох)<br>$\mathcal{O}(n d^2 + d^3)$ на итерацию — метод Ньютона — Рафсона |
| Пространственная сложность | $\mathcal{O}(n d)$ для хранения выборки |

---

## Инференс

Для объекта $\boldsymbol{x}_\text{new} \in \mathbb{R}^d$:

Вероятность положительного класса:

$$\hat{p} = \sigma(\boldsymbol{w}^\top \boldsymbol{x}_\text{new} + b)$$

Бинарный отклик при пороге $\tau \in (0, 1)$:

$$\hat{y} = \mathbb{I}[\hat{p} \ge \tau]$$

| Свойство | Описание |
| --- | --- |
| Временная сложность | $\mathcal{O}(d)$ на объект |
| Пространственная сложность | $\mathcal{O}(d)$ для хранения параметров |

---

## Достоинства и недостатки

Достоинства:

- Интерпретируемость: прямая оценка вероятностей и связь весов с отношение шансов
- Эффективность: быстрый инференс и минимальные требования к памяти
- Выпуклость: гарантированный глобальный оптимум при оптимизации

Недостатки и ограничения:

- Линейность: неспособность строить нелинейные границы без генерации признаков
- Чувствительность к [[масштабирование|масштабу]]: замедление сходимости и искажение регуляризации
- Чувствительность к [[коллинеарность|мультиколлинеарности]] и разлет весов при полной разделимости
