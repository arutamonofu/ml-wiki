## Свойства

| Свойство               | Значение                                                                                                                                                                                         |
| :--------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тип переменных         | $X$ — порядковая<br>$Y$ — порядковая                                                                                                                                                             |
| Что измеряет           | **Монотонная** связь между переменными:<br><br>- сила (близость значений к регрессионной прямой),<br>- направление.                                                                              |
| Диапазон значений      | $[-1; 1]$                                                                                                                                                                                        |
| Интерпретация значений | $+1$: абсолютно сильная положительная связь.<br>$-1$: абсолютно сильная отрицательная связь.<br>$0$: отсутствие связи.<br>Ближе к $±1$: более сильная связь.<br>Ближе к $0$: более слабая связь. |
| Обозначение            | - Для выборки: $r_{s}$<br>- Для генеральной совокупности: $\rho_{s}$                                                                                                                             |
| Проверка значимости    | [[t-критерий_стьюдента_для_коэффициента_корреляции_пирсона]]                                                                                                                                     |

## Вычисление

Если в наборе данных нет повторяющихся рангов:

$$1 - \frac{6 \sum_{i=1}^{n} d_i^2}{n(n^2 - 1)} $$

Где:

* $d_i$ — разность между рангами $i$-го наблюдения по двум переменным ($R(X_i) - R(Y_i)$).
* $\sum_{i=1}^{n} d_i^2$ — сумма квадратов разностей рангов.
* $n$ — количество пар наблюдений (объем выборки).

## Пример

Исследуется связь между оценками качества 8 образцов новой продукции, выставленными двумя независимыми экспертами (Эксперт 1 и Эксперт 2). Оценки выставлялись по шкале от 0 до 100 баллов. Были собраны следующие данные:

Оценки эксперта № 1: $[70, 85, 60, 90, 65, 100, 75, 95]$
Оценки эксперта № 2: $[75, 80, 65, 95, 70, 90, 60, 92]$

Вопрос: существует ли статистически значимая монотонная связь между оценками, выставленными двумя экспертами, на уровне значимости $\alpha = 0.05$? Какая это связь (положительная/отрицательная, сила)?

Решение:

1. Сформулируем $H_{0}$:
    * $\rho_{s} = 0$.

2. Ранжируем данные:
	- Эксперт № 1: $[3, 5, 1, 6, 2, 8, 4, 7]$.
	- Эксперт № 2: $[4, 5, 2, 8, 3, 6, 1, 7]$

3. Рассчитаем $d_{i}^2$:

| Образец | $R(X_{i})$ | $R(Y_{i})$ | $d_{i}^2$           |
| ------- | ---------- | ---------- | ------------------- |
| 1       | 3          | 4          | 1                   |
| 2       | 5          | 5          | 0                   |
| 3       | 1          | 2          | 1                   |
| 4       | 6          | 8          | 4                   |
| 5       | 2          | 3          | 1                   |
| 6       | 8          | 6          | 4                   |
| 7       | 4          | 1          | 9                   |
| 8       | 7          | 7          | 0                   |
|         |            |            | $\sum d_{i}^2 = 20$ |

4. Рассчитаем $r_{s}$:
	- $r_{s} = 1 - \frac{6 \cdot 20}{8 \cdot (8^2 - 1)} \approx 0.7619$

5. Рассчитаем $df$, $t$:
	- $df = 8 - 2 = 6$
	- $t = 0.7619 \cdot \sqrt{ \frac{8 - 2}{1 - 0.7619^2} } \approx 2.881$

6. Найдём $p$:
	- Для $t$ при $df$ $p$ примерно равен $0.028$.

7. Сравним $p$ и $\alpha$:
	- $0.028 < 0.05$.

Вывод: на уровне значимости $\alpha$ существует положительная монотонная связь между оценками, выставленными двумя экспертами, $r_{s} \approx 0.7619$.

## Python

```python
import numpy as np
from scipy import stats

# Данные из задачи
x_raw = np.array([70, 85, 60, 90, 65, 100, 75, 95])
y_raw = np.array([75, 80, 65, 95, 70, 90, 60, 92])

n = len(x_raw)
alpha = 0.05

print(f"Исследуется монотонная связь между оценками двух экспертов для {n} образцов.")
print(f"Оценки Эксперта 1 (X): {list(x_raw)}")
print(f"Оценки Эксперта 2 (Y): {list(y_raw)}")
print("-" * 30)

# 1. Формулировка гипотез
print("1. Формулировка гипотез:")
print("  H₀: ρs = 0 (статистически значимая монотонная связь отсутствует)")
print("  Hₐ: ρs ≠ 0 (существует статистически значимая монотонная связь)")
print("-" * 30)

# 2. Ранжирование данных (scipy.stats.spearmanr делает это внутри)
# Для наглядности покажем ранги:
ranks_x = stats.rankdata(x_raw)
ranks_y = stats.rankdata(y_raw)

print("2. Ранги данных:")
print(f"  Ранги R(X): {list(ranks_x)}")
print(f"  Ранги R(Y): {list(ranks_y)}")

# 3. Расчет dᵢ и dᵢ² (для ручной проверки, если нет связанных рангов)
d_i = ranks_x - ranks_y
d_i_sq = d_i**2
sum_d_i_sq = np.sum(d_i_sq)

print("\nТаблица для ручного расчета (если нет связанных рангов):")
print(f"  {'X_raw':<7} | {'Y_raw':<7} | {'R(X)':<5} | {'R(Y)':<5} | {'dᵢ':<5} | {'dᵢ²':<5}")
print(f"  {'-'*7} | {'-'*7} | {'-'*5} | {'-'*5} | {'-'*5} | {'-'*5}")
for i in range(n):
    print(f"  {x_raw[i]:<7} | {y_raw[i]:<7} | {ranks_x[i]:<5} | {ranks_y[i]:<5} | {d_i[i]:<5} | {d_i_sq[i]:<5}")
print(f"  Σdᵢ² = {sum_d_i_sq}")
print("-" * 30)

# 4. Расчет коэффициента корреляции Спирмена и p-value с помощью scipy
rho_s, p_value = stats.spearmanr(x_raw, y_raw)

print("4. Расчет коэффициента корреляции Спирмена (rₛ) и p-значения:")
# Расчет по формуле для случая без связанных рангов (для сравнения)
# Важно: stats.spearmanr корректно обрабатывает связанные ранги,
# тогда как простая формула ниже - нет. В нашем примере связанных рангов нет.
rho_s_manual = 1 - (6 * sum_d_i_sq) / (n * (n**2 - 1))
print(f"  rₛ (по формуле, если нет связей): 1 - (6 * {sum_d_i_sq}) / ({n} * ({n**2} - 1)) ≈ {rho_s_manual:.5f}")
print(f"  rₛ (scipy.stats.spearmanr): {rho_s:.5f}")
print(f"  p-значение (scipy.stats.spearmanr, двустороннее): {p_value:.5f}")


# 5. (Опционально) Ручной расчет t-статистики для проверки p-value
# Этот шаг не обязателен, так как scipy.stats.spearmanr уже дает p-value
if abs(rho_s) < 1: # Избегаем деления на ноль или корень из отрицательного
    t_stat_manual = rho_s * np.sqrt((n - 2) / (1 - rho_s**2))
    df = n - 2
    p_value_from_t = stats.t.sf(abs(t_stat_manual), df) * 2 # sf = survival function (1-cdf)
    print(f"\n  Проверка p-value через t-статистику:")
    print(f"  t-статистика (ручной расчет): {t_stat_manual:.3f} при df = {df}")
    print(f"  p-значение из t-статистики: {p_value_from_t:.5f}")
else:
    print(f"\n  |rₛ| = 1, t-статистика не рассчитывается стандартным образом.")

print("-" * 30)

# 6. Сравнение p-значения и α
print("6. Сравнение p-значения и α:")
print(f"  p-значение ({p_value:.5f}) vs α ({alpha})")
print("-" * 30)

# 7. Вывод
print("7. Вывод:")
if p_value < alpha:
    conclusion = (f"Поскольку p-значение ({p_value:.5f}) < α ({alpha}), "
                  f"мы отвергаем нулевую гипотезу H₀.\n"
                  f"Существует статистически значимая монотонная связь между оценками двух экспертов.\n"
                  f"Коэффициент корреляции Спирмена rₛ ≈ {rho_s:.3f} указывает на "
                  f"{'сильную' if abs(rho_s) > 0.7 else 'умеренную' if abs(rho_s) > 0.4 else 'слабую'} "
                  f"{'положительную' if rho_s > 0 else 'отрицательную'} монотонную связь.")
else:
    conclusion = (f"Поскольку p-значение ({p_value:.5f}) ≥ α ({alpha}), "
                  f"мы не можем отвергнуть нулевую гипотезу H₀.\n"
                  f"Статистически значимая монотонная связь между оценками двух экспертов не обнаружена "
                  f"(rₛ ≈ {rho_s:.3f}).")
print(conclusion)
```
