Линейная регрессия — модель, выражающая целевую переменную через линейную комбинацию признаков.

| Свойство     | Описание                                                   |
| ------------ | ---------------------------------------------------------- |
| Задача       | [[regression\|Регрессия]]                                  |
| Тип обучения | С учителем                                                 |
| Вход         | Матрица признаков $\mathbf{X} \in \mathbb{R}^{n \times d}$ |
| Выход        | Вектор откликов $\boldsymbol{y} \in \mathbb{R}^n$          |

> [!math]+ Математика
>
> Модель для объекта $f: \mathbb{R}^d \to \mathbb{R}$:
>
> $$f(\boldsymbol{x}) = \boldsymbol{w}^\top \boldsymbol{x} + b$$
>
> Модель для выборки:
>
> $$\boldsymbol{y} = \mathbf{X}\boldsymbol{w} + b\mathbf{1}$$
>
> Обозначения:
>
> - $\mathbf{X} \in \mathbb{R}^{n \times d}$ — матрица признаков
>
> - $\boldsymbol{w} \in \mathbb{R}^d$ — вектор весов
>
> - $b \in \mathbb{R}$ — свободный член
>
> - $\mathbf{1} \in \mathbb{R}^n$ — вектор из единиц

---

## Обучение

Оптимизация параметров $\boldsymbol{w}, b$ путём минимизации функции потерь.

Аналитическое решение МНК для MSE при $\tilde{\mathbf{X}} = [\mathbf{X} \mid \mathbf{1}] \in \mathbb{R}^{n \times (d+1)}$ и $\tilde{\boldsymbol{w}} = [\boldsymbol{w}; b] \in \mathbb{R}^{d+1}$:

$$\tilde{\boldsymbol{w}}^* = (\tilde{\mathbf{X}}^\top \tilde{\mathbf{X}})^{-1} \tilde{\mathbf{X}}^\top \boldsymbol{y}$$

Численные методы: градиентный спуск и его варианты.

| Свойство | Описание |
| --- | --- |
| Обучаемые параметры | Вектор весов $\boldsymbol{w} \in \mathbb{R}^d$, свободный член $b \in \mathbb{R}$ |
| Гиперпараметры | Свободный член, функция потерь, оптимизатор, темп обучения, регуляризация |
| Временная сложность | $\mathcal{O}(n d^2 + d^3)$ — аналитическое решение<br>$\mathcal{O}(n d e)$ — градиентный спуск ($e$ эпох) |
| Пространственная сложность | $\mathcal{O}(nd)$ для выборки |

---

## Инференс

Расчёт для нового объекта $\boldsymbol{x}_\text{new} \in \mathbb{R}^d$:

$$\hat{y} = \boldsymbol{w}^\top \boldsymbol{x}_\text{new} + b$$

| Свойство | Описание |
| --- | --- |
| Временная сложность | $\mathcal{O}(d)$ на объект |
| Пространственная сложность | $\mathcal{O}(d)$ для параметров |

---

## Достоинства и недостатки

Достоинства:

- Прямая интерпретируемость весов
- Высокая скорость и малый расход памяти
- Наличие точного аналитического решения

Недостатки:

- Моделирование только линейных связей
- Чувствительность к [[масштабирование|масштабу признаков]]
- Уязвимость к [[коллинеарность|мультиколлинеарности]] и [[выбросы|выбросам]]
