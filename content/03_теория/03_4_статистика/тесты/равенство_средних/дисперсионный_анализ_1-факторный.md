## Свойства

| Свойство                             | Значение                                                                                                                                                                                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Типы переменных                      | Независимые — категориальные, зависимая — количественная.                                                                                                                                                                                                |
| Количество выборок (уровней фактора) | $\geq 3$ (технически можно для 2 — эквивалентно t-тесту)                                                                                                                                                                                                 |
| Тип связи между выборками            | Несвязанные                                                                                                                                                                                                                                              |
| Тип наблюдений в выборке             | Независимые                                                                                                                                                                                                                                              |
| Нулевая гипотеза                     | Средние значения во всех генеральных совокупностях, из которых взяты выборки, равны.                                                                                                                                                                     |
| Распределение критерия               | Распределение Фишера-Снедекора                                                                                                                                                                                                                           |
| Условия                              | - Если размер выборки меньше 30, то нормальное распределение генеральной совокупности, из которой она взята;<br>- Однородность дисперсий в генеральных совокупностях, из которых взяты выборки;<br>- Отсутствие значительного числа выбросов в выборках. |
| Обозначение                          | $F$                                                                                                                                                                                                                                                      |

## Вычисление

$$\frac{MS_{B}}{MS_{W}}$$

|   Обозначение   | **Понятие**                                | **Описание**                                                            |                         **Формула**                          |
| :-------------: | ------------------------------------------ | ----------------------------------------------------------------------- | :----------------------------------------------------------: |
|    $MS_{B}$     | Межгрупповая дисперсия                     | Средний квадрат отклонения средних значений групп от общего среднего.   |                  $\frac{SS_{B}}{{df}_{B}}$                   |
|    $MS_{W}$     | Внутригрупповая дисперсия                  | Средний квадрат отклонения наблюдений внутри группы от среднего группы. |                  $\frac{SS_{W}}{{df}_{W}}$                   |
|    $SS_{B}$     | Межгрупповая сумма квадратов отклонений    | Сумма квадратов отклонений средних значений групп от общего среднего.   |       $\sum_{i=1}^m N_i (\bar{X}_i - \bar{\bar{X}})^2$       |
|    $SS_{W}$     | Внутригрупповая сумма квадратов отклонений | Сумма квадратов отклонений наблюдений внутри группы от среднего группы. | $\sum_{i=1}^{m} \sum_{j=1}^{N_i} (X_{ij} - \bar{X}_i)^2$<br> |
|      $SST$      | Общая сумма квадратов отклонений           | Сумма квадратов отклонений всех наблюдений от общего среднего.          |    $\sum_{i=1}^{m} \sum_{j=1}^{N_i} (X_{ij} - \bar{X})^2$    |
|  ${df}_{{B}}$   | Межгрупповое число степеней свобод         | Число групп минус один.                                                 |                           $m - 1$                            |
|  ${df}_{{W}}$   | Внутригрупповое число степеней свобод      | Сумма количеств степеней свобод групп.                                  |                           $N - m$                            |

> [!Info]
> Анализируется, насколько общая дисперсия обусловлена межгрупповой или внутригрупповой дисперсией. Если это соотношение равно 1, тогда степень дисперсии, возникающей из-за внутригрупповых различий, равна дисперсии, возникающей из-за межгрупповых различий, а любые различия между группами не являются статистически значимыми. По мере увеличения средней разницы между группами (и возрастания числителя дроби) также возрастает и значение $F$-критерия. По мере возрастания значения $F$ оно становится все более крайним по отношению к распределению всех значений $F$. При этом все больше вероятность того, что на него повлияло что-то еще, помимо случайности.

## Пример

Металлургический завод получает сырье (например, руду определенного типа) от трёх разных поставщиков (Поставщик 1, Поставщик 2, Поставщик 3). Инженера по качеству беспокоит, что качество сырья может различаться в зависимости от поставщика, что влияет на выход годной продукции (например, на процент содержания целевого металла после первичной обработки).

Были взяты случайные пробы сырья от каждого поставщика за последний месяц и измерен процент содержания целевого металла:

*   Поставщик 1: $84\%, 86\%, 83\%, 87\%, 85\%$ ($N_1=5$)
*   Поставщик 2: $86\%, 88\%, 85\%, 89\%, 87\%$ ($N_2=5$)
*   Поставщик 3: $83\%, 85\%, 82\%, 86\%, 84\%$ ($N_3=5$)

Вопрос: существуют ли статистически значимые различия в среднем проценте содержания целевого металла в сырье, поставляемом тремя разными поставщиками? Влияет ли выбор поставщика на качество сырья? Уровень значимости $\alpha = 0.05$.

Решение:

1. Сформулируем $H_{0}$:
	- Средний процент содержания целевого металла одинаков для всех трех поставщиков: $\mu_1 = \mu_2 = \mu_3$.

2. Рассчитаем $\bar{X}_{1}$, $\bar{X}_{2}$, $\bar{X}_{3}$, $\bar{\bar{X}}$:
	- $\bar{X}_1 = \frac{84+86+83+87+85}{5} = \frac{425}{5} = 85$
	* $\bar{X}_2 = \frac{86+88+85+89+87}{5} = \frac{435}{5} = 87$
	* $\bar{X}_3 = \frac{83+85+82+86+84}{5} = \frac{420}{5} = 84$
	* $\bar{\bar{X}} = \frac{425 + 435 + 420}{5 + 5 + 5} = \frac{1280}{15} \approx 85.333$

3. Рассчитаем $SSB$, $SSW$:
	- $SSB = 5(85 - 85.333)^2 + 5(87 - 85.333)^2 + 5(84 - 85.333)^2 = 23.335$
	- $SSW = \sum (X_{ij} - \bar{X}_i)^2 = 10 + 10 + 10 = 30$

4. Рассчитаем $df_{B}$, $df_{W}$:
	- $df_{B} = 3 - 1 = 2$
	- $df_{W} = 15 - 3 = 12$

5. Рассчитаем $MS_{B}$, $MS_{W}$:
	*   $MS_B = \frac{23.335}{2} = 11.6675$
	*   $MS_W = \frac{30}{12} \approx 2.5$

6. Рассчитаем $F$:
	*   $F = \frac{11.6675}{2.5} \approx 4.67$

7. Найдём критическое значение $F$:
	- Для $\alpha$, $df_{B}$, $df_{W}$ критическое значение $F$ примерно равно $3.89$. 

8. Сравним рассчитанное и критическое значения $F$:
	- $4.67 > 3.89$.

Вывод: на уровне значимости $\alpha = 0.05$ существуют различия в среднем проценте содержания целевого металла в сырье от разных поставщиков.
