---
Метод $k$ ближайших соседей — непараметрический алгоритм, определяющий отклик объекта по $k$ ближайшим объектам обучающей выборки с помощью голосования или усреднения.

| Свойство     | Описание                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| Задачи       | [[regression\|Регрессия]], [[classification\|классификация]]                                             |
| Тип обучения | С учителем                                                                                               |
| Вход         | Матрица признаков $\mathbf{X} \in \mathbb{R}^{m \times d}$                                               |
| Выход        | Вектор откликов $\hat{\boldsymbol{y}} \in \mathbb{R}^m$ или $\hat{\boldsymbol{y}} \in \{1, \dots, K\}^m$ |

> [!math]+ Математика
>
> Модель $f: \mathbb{R}^{m \times d} \to \mathcal{Y}^m$:
>
> $$\boldsymbol{y}_\text{pred} = \text{kNN}_\text{reg}(\mathbf{X}, \mathbf{X}_\text{train}, \boldsymbol{y}_\text{train})$$
>
> $$\boldsymbol{y}_\text{pred} = \text{kNN}_\text{cls}(\mathbf{X}, \mathbf{X}_\text{train}, \boldsymbol{y}_\text{train})$$
>
> Для объекта $\boldsymbol{x}_j$:
>
> - Регрессия: $y_{\text{pred}, j} = \frac{\sum_{i \in N_k(\boldsymbol{x}_j)} w_{j,i} y_{\text{train}, i}}{\sum_{i \in N_k(\boldsymbol{x}_j)} w_{j,i}}$
>
> - Классификация: $y_{\text{pred}, j} = \operatorname{argmax}_{c \in \{1, \dots, K\}} \sum_{i \in N_k(\boldsymbol{x}_j)} w_{j,i} \mathbb{I}[y_{\text{train}, i} = c]$
>
> Где:
>
> - $\mathbf{X} \in \mathbb{R}^{m \times d}$ — оцениваемые объекты;
>
> - $\mathbf{X}_\text{train} \in \mathbb{R}^{n \times d}$, $\boldsymbol{y}_\text{train} \in \mathcal{Y}^n$ — обучающая выборка;
>
> - $N_k(\boldsymbol{x}_j)$ — индексы $k$ ближайших соседей к $\boldsymbol{x}_j$;
>
> - $w_{j,i}$ — вес $i$-го соседа ($w_{j,i} = 1$ или $w_{j,i} = \frac{1}{\rho(\boldsymbol{x}_j, \boldsymbol{x}_{\text{train}, i}) + \varepsilon}$);
>
> - $\mathbb{I}[\cdot]$ — индикаторная функция;
>
> - Расстояние Минковского: $\rho(\boldsymbol{x}_j, \boldsymbol{x}_{\text{train}, i}) = \|\boldsymbol{x}_j - \boldsymbol{x}_{\text{train}, i}\|_p = \left( \sum_{l=1}^{d} |x_{j,l} - x_{\text{train}, i, l}|^p \right)^{\frac{1}{p}}$.

---

## Обучение

Обучение в явном виде отсутствует (ленивое обучение). Выборка сохраняется в память или индексируется в дерево (KD-дерево, Ball-дерево) для ускорения поиска.

| Свойство | Описание |
| --- | --- |
| Обучаемые параметры | Отсутствуют ($\mathbf{X}_\text{train}, \boldsymbol{y}_\text{train}$) |
| Гиперпараметры | Соседи $k$, метрика $\rho$, вес $w_{j,i}$, тип дерева |
| Временная сложность | $\mathcal{O}(1)$ сохранение<br>$\mathcal{O}(d \cdot n \log n)$ построение дерева |
| Пространственная сложность | $\mathcal{O}(n d)$ |

---

## Инференс

Для $\boldsymbol{x}_\text{new} \in \mathbb{R}^d$ рассчитываются расстояния до обучающих объектов, выделяются $k$ соседей $N_k(\boldsymbol{x}_\text{new})$ и вычисляется отклик $\hat{y} = f(\boldsymbol{x}_\text{new})$.

| Свойство | Описание |
| --- | --- |
| Временная сложность | $\mathcal{O}(n d)$ на объект при полном переборе<br>$\mathcal{O}(d \log n)$ на объект при обходе дерева ($d \ll n$) |
| Пространственная сложность | $\mathcal{O}(n d)$ |

---

## Достоинства и недостатки

Достоинства:

- Интерпретируемость: объяснение предсказаний через похожие объекты
- Произвольная геометрия: моделирование сложных разделяющих поверхностей
- Отсутствие обучения: добавление данных за $\mathcal{O}(1)$

Недостатки:

- Чувствительность к [[масштабирование|масштабу признаков]]
- Высокая сложность инференса: значительные затраты времени и памяти
- Проклятие размерности: деградация качества в пространствах высокой размерности
- Неспособность к экстраполяции: предсказания ограничены диапазоном обучающей выборки
