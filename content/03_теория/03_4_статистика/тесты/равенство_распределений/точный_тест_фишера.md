## Вычисление

Точный тест Фишера рассчитывает сумму вероятностей наблюдаемой и менее вероятных таблиц сопряжённости.

Вероятность таблицы:

$$p = \frac{C_{a+b}^a \cdot C_{c+d}^c}{C_{n}^{a+c}} = \frac{r_{1}!r_{2}!c_{1}!c_{2}!}{n!a!b!c!d!}$$

|          | Успех             | Неуспех           | Сумма             |
| -------- | ----------------- | ----------------- | ----------------- |
| Группа 1 | $a$               | $b$               | $a + b$ ($r_{1}$) |
| Группа 2 | $c$               | $d$               | $c + d$ ($r_{2}$) |
| Сумма    | $a + c$ ($c_{1}$) | $b + d$ ($c_{2}$) | $n$               |

> [!Info]
> Нулевая гипотеза заключается в том, что вероятность успеха одинакова в обеих группах:
> 
> $$P(\text{Успех} \mid \text{Группа 1}) = P(\text{Успех} \mid \text{Группа 2})$$
> 
> Проверка нулевой гипотезы заключается в вычислении $P(X = a \mid X + Y = a + c)$ — вероятности получить таблицу с $a$ успехов в 1-й группе при условии, что сумма успехов в обеих группах равна $a + c$ (это автоматически предопределяет $b, c, d$).
> 
> $$P(X = a \mid X + Y = a + c) = \frac{P(X = a) \cdot P(Y = c)}{P(X + Y = a + c)} = \frac{C_{a+b}^a \cdot C_{c+d}^c}{C_{n}^{a+c}} = \frac{r_{1}!r_{2}!c_{1}!c_{2}!}{n!a!b!c!d!}$$
> 
> Таким образом, в знаменателе — вероятность получить любую таблицу в пределах исходной суммы успехов. В числителе — вероятность получить данную пару $a$ и $c$ (в пределах маргинальных сумм). Деление вычисляет условную вероятность.

## Пример

Маркетинговая команда хочет протестировать два варианта темы письма для email-рассылки. Из-за ограниченного бюджета и специфики целевой аудитории, проводится небольшой пилотный тест на двух маленьких, случайно выбранных группах пользователей.

- Группа A: получила письмо с Темой 1.
- Группа Б: получила письмо с Темой 2.

Собраны следующие данные по кликам:

| Группа    | Кликнули по ссылке | Не кликнули по ссылке | Всего в группе |
| --------- | ------------------ | --------------------- | -------------- |
| **A**     | 1                  | 9                     | 10             |
| **Б**     | 5                  | 7                     | 12             |
| **Всего** | 6                  | 16                    | 22             |

Вопрос: существует ли статистически значимая разница в CTR между Темой 1 и Темой 2? Уровень значимости $\alpha = 0.05$.

Решение:

1. Сформулируем $H_{0}$: распределения в выборках А и Б одинаковы.
2. Рассчитаем вероятность получения этой таблицы или любой менее вероятной:
	- $P(a = 1 \mid a + c = 6) \approx 0.106$ (эта)
	- $P(a = 0 \mid a + c = 6) \approx 0.011$
	- $P(a = 5 \mid a + c = 6) \approx 0.027$
	- $P(a = 6 \mid a + c = 6) \approx 0.001$
	- $p \approx 0.106 + 0.011 + 0.027 + 0.001 = 0.146$
3. Сравним $p$ и $\alpha$: $0.146 > 0.05$. Не отвергаем нулевую гипотезу.

Вывод: на уровне значимости $0.05$ распределения в выборках не отличаются, переменные темы письма и клика по ссылке независимы.

### Python

```python
import numpy as np
from scipy.stats import fisher_exact

# Вводные данные

observed_table = np.array([
    [1, 9],
    [5, 7]
])
alpha = 0.05


# Расчёт p-значения

_, p_value = fisher_exact(observed_table, alternative='two-sided')


# Вывод

if p_value < alpha:
    print(
        f"P-значение ({p_value:.3f}) < α ({alpha}). "
        "Отвергаем нулевую гипотезу в пользу альтернативной."
    )
else:
    print(
        f"P-значение ({p_value:.3f}) ≥ α ({alpha}). "
        "Не отвергаем нулевую гипотезу."
    )
```
