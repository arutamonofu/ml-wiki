BCE loss (Binary Cross-Entropy) — [[дифференцирование|дифференцируемая]] функция потерь бинарной классификации, оценивающая расхождение вероятностных предсказаний и истинных меток.

| Свойство       | Описание                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------- |
| Тип задачи     | [[classification\|Классификация]]                                                        |
| Вход           | Векторы предсказаний $\mathbf{\hat{y}} \in (0, 1)^n$ и меток $\mathbf{y} \in \{0, 1\}^n$ |
| Выход          | Скаляр $L_{\text{BCE}} \in [0, +\infty)$                                                 |
| Гиперпараметры | Отсутствуют                                                                              |
| Свойства       | Выпукла по предсказаниям, непрерывно дифференцируема                                     |

Математическое определение в скалярной форме:

$$L_{\text{BCE}} = -\frac{1}{n} \sum_{i=1}^{n} \Big[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \Big]$$

В векторной форме:

$$L_{\text{BCE}} = -\frac{1}{n} \Big( \mathbf{y}^T \log(\mathbf{\hat{y}}) + (\mathbf{1} - \mathbf{y})^T \log(\mathbf{1} - \mathbf{\hat{y}}) \Big)$$

Градиент по вектору предсказаний:

$$\nabla_{\mathbf{\hat{y}}} L_{\text{BCE}} = \frac{1}{n} (\mathbf{\hat{y}} - \mathbf{y}) \oslash \Big( \mathbf{\hat{y}} \odot (\mathbf{1} - \mathbf{\hat{y}}) \Big)$$

## Достоинства и недостатки

Достоинства:

- Быстрая сходимость: логарифмический штраф ускоряет обучение на сложных примерах
- Выпуклость по предсказаниям: исключает локальные минимумы в пространстве выходов
- Теоретическая обоснованность: эквивалентна максимизации правдоподобия Бернулли
- Алгоритмическая простота: не требует гиперпараметров

Недостатки и ограничения:

- Численная нестабильность: расчет логарифма близких к нулю значений приводит к неопределенности
- Чувствительность к [[дисбаланс_классов|дисбалансу]]: градиент доминируется ошибками мажоритарного класса
