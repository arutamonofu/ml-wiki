---
title: Categorical cross-entropy
aliases:
  - CCE loss
---
CCE loss (categorical cross-entropy) — функция потерь многоклассовой классификации, оценивающая расхождение между предсказанным и истинным распределениями вероятностей. Применяется как [[дифференцирование|дифференцируемый]] критерий в [[sgd|градиентной]] [[оптимизация|оптимизации]].

| Свойство       | Описание                                                                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тип задачи     | Многоклассовая [[classification\|классификация]]                                                                                                         |
| Вход           | Вероятности $\mathbf{\hat{Y}} \in (0, 1)^{n \times K}$ ($\sum_k \hat{y}_{i,k} = 1$), метки $\mathbf{Y} \in \{0, 1\}^{n \times K}$ ($\sum_k y_{i,k} = 1$) |
| Выход          | Скаляр $L_{\text{CCE}} \in [0, +\infty)$                                                                                                                 |
| Гиперпараметры | Отсутствуют (во фреймворках: `weight`, `label_smoothing`, агрегация)                                                                                     |
| Свойства       | Выпуклая, непрерывно дифференцируемая                                                                                                                    |

Скалярная форма:

$$L_{\text{CCE}} = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k=1}^{K} y_{i, k} \log(\hat{y}_{i, k})$$

Матричная форма (поэлементный логарифм):

$$L_{\text{CCE}} = -\frac{1}{n} \operatorname{Tr}\left(\mathbf{Y}^T \log(\mathbf{\hat{Y}})\right)$$

Градиент по вероятностям:

$$\nabla_{\mathbf{\hat{Y}}} L_{\text{CCE}} = -\frac{1}{n} (\mathbf{Y} \oslash \mathbf{\hat{Y}})$$

Градиент по логитам $\mathbf{Z}$ при $\mathbf{\hat{Y}} = \operatorname{softmax}(\mathbf{Z})$:

$$\nabla_{\mathbf{Z}} L_{\text{CCE}} = \frac{1}{n} (\mathbf{\hat{Y}} - \mathbf{Y})$$

---

## Достоинства и недостатки

Достоинства:

- Совместное вычисление с Softmax упрощает градиент по логитам до $\frac{1}{n}(\mathbf{\hat{Y}} - \mathbf{Y})$ и предотвращает затухание градиентов;
- Эквивалентна максимизации правдоподобия мультиномиального распределения и минимизации KL-дивергенции;
- Подходит для взаимно исключающих классов;
- Не содержит собственных гиперпараметров.

Недостатки и ограничения:

- Вычисление $\log(\hat{y}_{i,k})$ при $\hat{y}_{i,k} \to 0$ требует клиппирования или применения LogSumExp к логитам;
- Чувствительна к ошибочной разметке из-за большого штрафа за уверенные неверные предсказания.
