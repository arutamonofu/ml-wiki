## Свойства

| Свойство                            | Значение                                                                                                               |
| :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| **Тип данных**                      | Количественный                                                                                                         |
| **Количество выборок**              | 2 или более                                                                                                            |
| **Тип связи между выборками**       | Несвязанные                                                                                                            |
| **Тип наблюдений в выборке**        | Независимые                                                                                                            |
| **Нулевая гипотеза ($H_0$)**        | Дисперсии в генеральных совокупностях, из которых взяты выборки, равны ($\sigma_1^2 = \sigma_2^2 = ... = \sigma_k^2$). |
| **Альтернативная гипотеза ($H_1$)** | Хотя бы одна дисперсия отличается от других.                                                                           |
| **Распределение критерия**          | Распределение Фишера-Снедекора                                                                                         |
| **Обозначение статистики**          | $W$ (или $F$)                                                                                                          |

## Вычисление

$$W = \frac{(N-k)}{(k-1)} \frac{\sum_{i=1}^{k} N_i (\bar{Z}_i - \bar{Z})^2}{\sum_{i=1}^{k} \sum_{j=1}^{N_i} (Z_{ij} - \bar{Z}_i)^2}$$
  Где:
  
- $N$ — общее количество наблюдений во всех группах ($N = \sum N_i$)
- $k$ — количество групп
- $N_i$ — количество наблюдений в $i$-ой группе
- $\bar{Z}_i$ — среднее значение $Z_{ij}$ для $i$-ой группы
- $\bar{Z}$ — общее среднее значение всех $Z_{ij}$

Степени свободы: 

$$df_1 = k-1, df_2 = N-k$$

#### Пример

Агрономы исследуют два новых метода обработки почвы и их влияние на стабильность урожайности пшеницы.

Получены следующие данные:
* Метод А: $[17, 20, 23, 18, 22, 16, 24, 19, 21, 20]$ (10 наблюдений)
* Метод Б: $[20, 25, 30, 18, 26, 22, 32, 23, 27, 24, 19]$ (11 наблюдений)

Вопрос: можно ли считать, что дисперсии урожайности для двух методов обработки почвы одинаковы? Уровень значимости $\alpha = 0.05$.

Решение:

```python
import numpy as np
from scipy.stats import levene, f
import matplotlib.pyplot as plt

# Вводные данные

group1 = np.array([17, 20, 23, 18, 22, 16, 24, 19, 21, 20])
group2 = np.array([20, 25, 30, 18, 26, 22, 32, 23, 27, 24, 19])
m = 2
n = len(group1) + len(group2)
alpha = 0.05


# Расчёт W-статистики и p-значения

w_stat, p_value = levene(group1, group2, center='mean')


# Вывод

if p_value < alpha:
    print(
        f"P-значение ({p_value:.3f}) < α ({alpha}). "
        "Отвергаем нулевую гипотезу в пользу альтернативной."
    )
else:
    print(
        f"P-значение ({p_value:.3f}) ≥ α ({alpha}). "
        "Не отвергаем нулевую гипотезу."
    )


# Визуализация

dfB = m - 1
dfW = n - m
critical_w_stat = f.ppf(1 - alpha, dfB, dfW)
x_values = np.linspace(0, max(w_stat * 1.1, critical_w_stat * 1.1), 200)
probability_density = f.pdf(x_values, dfB, dfW)

plt.figure(figsize=(10, 6), dpi=100)
plt.plot(
    x_values,
    probability_density,
    color="C7",
    label=f"Распределение F({dfB}, {dfW})",
)
plt.axvline(critical_w_stat, color="C3", linestyle="--", label=f"Критическое значение W")
plt.axvline(w_stat, color="C4", linestyle="--", label="Рассчитанное значение W")
plt.fill_between(x_values, probability_density, where=(x_values >= w_stat), color='C4', alpha=0.5, label="Вероятность")

plt.xlabel("F")
plt.ylabel("Плотность вероятности")
plt.title("Тест Левене")
plt.legend()
plt.show()
```

Вывод: $P$-значение ($0.124$) ≥ $\alpha$ ($0.05$). Не отвергаем нулевую гипотезу.
