Случайный лес — ансамблевый непараметрический алгоритм машинного обучения, композиция независимых решающих деревьев, обученных с применением бэггинга и метода случайных подпространств.

| Свойство     | Описание                                                                            |
| ------------ | ----------------------------------------------------------------------------------- |
| Задачи       | [[regression\|Регрессия]], [[classification\|классификация]]                        |
| Тип обучения | С учителем                                                                          |
| Вход         | Матрица признаков $\mathbf{X} \in \mathbb{R}^{N \times d}$                          |
| Выход        | Вектор предсказаний $\hat{\boldsymbol{y}} \in \mathbb{R}^N$ или $\{1, \dots, K\}^N$ |

> [!math]+ Математика
> Модель $f: \mathbb{R}^{N \times d} \to \mathcal{Y}^N$.
>
> Регрессия:
>
> $$\hat{\boldsymbol{y}} = \frac{1}{B} \sum_{b=1}^{B} \boldsymbol{h}_b(\mathbf{X})$$
>
> Классификация:
>
> $$\hat{\boldsymbol{y}} = \operatorname{argmax}_{c \in \{1, \dots, K\}} \sum_{b=1}^{B} \mathbb{I}[\boldsymbol{h}_b(\mathbf{X}) = c]$$
>
> Для объекта $\boldsymbol{x}_i$:
>
> - Регрессия: $\hat{y}_i = \frac{1}{B} \sum_{b=1}^{B} h_b(\boldsymbol{x}_i)$;
> - Классификация: $\hat{y}_i = \operatorname{argmax}_{c \in \{1, \dots, K\}} \sum_{b=1}^{B} \mathbb{I}[h_b(\boldsymbol{x}_i) = c]$.
>
> Обозначения:
>
> - $\mathbf{X} \in \mathbb{R}^{N \times d}$ — матрица признаков;
> - $B$ — количество деревьев;
> - $\boldsymbol{h}_b(\mathbf{X})$ — $b$-е дерево на бутстрап-выборке;
> - $\mathbb{I}[\cdot]$ — индикаторная функция.

---

## Обучение

Построение $B$ деревьев на [[bootstrapping|бутстрап]]-выборках $\mathbf{X}^{(b)}$ с выбором $m \le d$ случайных признаков в каждом узле.

Оценка обобщающей способности выполняется через Out-of-Bag (OOB) ошибку на объектах, не вошедших в бутстрап-выборку.

| Свойство | Описание |
| --- | --- |
| Параметры | Структуры узлов и значения в листьях $\{h_b\}_{b=1}^B$ |
| Гиперпараметры | Число деревьев $B$, размер подпространства $m$, параметры базовых деревьев |
| Временная сложность | $\mathcal{O}(B \cdot m \cdot N \log N)$ |
| Пространственная сложность | $\mathcal{O}(B \cdot (N + \bar{M}))$, где $\bar{M}$ — среднее число листьев |

---

## Инференс

Для нового объекта $\boldsymbol{x}_\text{new} \in \mathbb{R}^d$:

Усреднение (регрессия) или голосование (классификация) предсказаний базовых деревьев:

$$\hat{y} = f(\boldsymbol{x}_\text{new})$$

| Свойство | Описание |
| --- | --- |
| Временная сложность | $\mathcal{O}(B \cdot \bar{h})$ на объект, где $\bar{h}$ — средняя глубина деревьев |
| Пространственная сложность | $\mathcal{O}(B \cdot \bar{M})$ для хранения всех деревьев |

---

## Достоинства и недостатки

Достоинства:

- Устойчивость к переобучению, шуму и коррелированным признакам;
- Инвариантность к масштабу признаков и монотонным преобразованиям;
- Моделирование сложных нелинейных зависимостей;
- Эффективное параллельное обучение.

Недостатки:

- Низкая интерпретируемость;
- Высокие затраты памяти и задержка инференса;
- Отсутствие экстраполяции за пределы обучающего диапазона.
