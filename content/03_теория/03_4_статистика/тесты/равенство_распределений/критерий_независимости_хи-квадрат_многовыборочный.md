## Свойства

| Свойство                  | Значение                                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Тип данных                | Категориальный                                                                                                     |
| Количество выборок        | $\geq 2$                                                                                                           |
| Тип связи между выборками | Несвязанные                                                                                                        |
| Тип наблюдений в выборке  | Независимые                                                                                                        |
| Нулевая гипотеза          | Распределение (вероятностей полной группы событий) в выборках одинаково, или категориальные переменные независимы. |
| Распределение критерия    | [[Распределение хи-квадрат]]                                                                                       |
| Условия                   | - Ни одно ожидаемое значение не меньше 1.<br>- Не более чем у 20% ожидаемое значение меньше 5.                     |
| Обозначение               | $\chi^2$                                                                                                           |

> [!Info]
> Квадратный корень каждого слагаемого: $X = \sqrt{  \frac{(O - E)^2}{E} }$  — аппроксимируется стандартной нормальной случайной величиной $X \sim N(0, 1)$ (при $E$ больше 5). Поэтому их сумма имеет распределение хи-квадрат.

## Вычисление

$$\sum \frac{(O - E)^2}{E}$$

$O$ — наблюдаемая частота
$E$ — ожидаемая частота: $E_{ij} = \frac{r_{i} \cdot c_{j}}{N}$ — произведение суммы строки $i$ и суммы столбца $j$, поделённое на сумму всех наблюдений.

$$df = (r - 1)(c - 1)$$

$r$ — количество значений $X$ (категорий, строк)
$c$ — количество значений $Y$ (категорий, столбцов)

## Пример

Аналитик хочет проверить, влияет ли цвет кнопки «Добавить в корзину» на веб-странице товара на то, нажмёт ли пользователь на эту кнопку. Было проведено A/B-тестирование:

- Группа A: Пользователи видели страницу со стандартной синей кнопкой.
- Группа B: Пользователи видели страницу с новой зелёной кнопкой.

Собраны следующие данные за период тестирования:

|                 | Нажали на кнопку | Не нажали на кнопку | Всего пользователей |
| --------------- | ---------------- | ------------------- | ------------------- |
| **А (Синяя)**   | 155              | 845                 | 1000                |
| **Б (Зеленая)** | 190              | 810                 | 1000                |
| **Всего**       | 345              | 1655                | 2000                |

Вопрос: зависимы ли переменные цвета кнопки и нажатия на кнопку? Уровень значимости $\alpha = 0.05$.

1. Сформулируем $H_{0}$: 
	- Распределения в выборках А и Б одинаковы, или переменные цвета кнопки и нажатия на кнопку независимы.
2. Рассчитаем ожидаемые частоты $E$:
	- $E(\text{A, Нажали}) = (1000 \cdot 345) / 2000 = 172.5$
	- $E(\text{A, Не нажали}) = (1000 \cdot 1655) / 2000 = 827.5$
	- $E(\text{B, Нажали}) = (1000 \cdot 345) / 2000 = 172.5$
	- $E(\text{B, Не нажали}) = (1000 \cdot 1655) / 2000 = 827.5$
3. Рассчитаем $\frac{(O - E)^2}{E}$ и $\chi^2$:
    - $\chi^2 = 1.775 + 0.370 + 1.775 + 0.370 = 4.29$
4. Определим число степеней свободы $df$:
	- $df = (2 - 1) \cdot (2 - 1) = 1 \cdot 1 = 1$
5. Найдём критическое значение $\chi^2$:
	- Для $\alpha$ и $df$ критическое значение $\chi^2$ равно $3.841$.
6. Сравним рассчитанное и критическое значения $\chi^2$: $4.29 > 3.841$. Отвергаем нулевую гипотезу в пользу альтернативной.

Вывод: на уровне значимости $0.05$ распределения в выборках отличаются, переменные цвета кнопки и нажатия на кнопку зависимы.

### Python

```python
import numpy as np
from scipy.stats import chi2_contingency, chi2

# Вводные данные

observed_frequencies = np.array([
    [155, 845],
    [190, 810],
])
alpha = 0.05


# Расчёт статистики χ² и p-значения

chi2_stat, p_value, dof, expected_freq = chi2_contingency(observed_frequencies)


# Вывод

if p_value < alpha:
    print(
        f"P-значение ({p_value:.3f}) < α ({alpha}). "
        "Отвергаем нулевую гипотезу в пользу альтернативной."
    )
else:
    print(
        f"P-значение ({p_value:.3f}) ≥ α ({alpha}). "
        "Не отвергаем нулевую гипотезу."
    )


# Визуализация

x_values = np.linspace(0, max(10, chi2_stat + 2), 200)
probability_density = chi2.pdf(x_values, dof)
critical_chi2_stat = chi2.ppf(1 - alpha, dof)

plt.figure(figsize=(8, 5), dpi=100)
plt.plot(
    x_values,
    probability_density,
    color="C7",
    label=f"Распределение χ²({dof})",
)
plt.axvline(critical_chi2_stat, color="C3", linestyle="--", label=f"Критическое значение χ²")
plt.axvline(chi2_stat, color="C4", linestyle="--", label="Рассчитанное значение χ²")
plt.fill_between(
    x_values,
    probability_density,
    where=(x_values >= chi2_stat),
    color="C4",
    alpha=0.5,
    label="Вероятность события",
)

plt.xlabel("χ²")
plt.ylabel("Плотность вероятности")
plt.title("Критерий независимости χ²")
plt.legend()
plt.show()
```
