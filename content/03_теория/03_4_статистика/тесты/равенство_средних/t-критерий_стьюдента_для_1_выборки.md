## Свойства

| Свойство                 | Значение                                                                                      |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| Тип данных               | Количественный                                                                                |
| Количество выборок       | 1                                                                                             |
| Тип наблюдений в выборке | Независимые                                                                                   |
| Нулевая гипотеза         | Среднее значение ГС выборки равно ожидаемому значению.                                        |
| Распределение критерия   | [[Распределение Стьюдента]]                                                                   |
| Условия                  | - Нормальное распределение в выборке;<br>- Отсутствие значительного числа выбросов в выборке. |
| Обозначение              | $t$                                                                                           |

## Вычисление

$$\frac{\overline{X} - \mu}{\frac{SD}{\sqrt{n}}}$$

Число степеней свободы:

$$df = n - 1$$

> [!INFO]
> t-критерий Стьюдента — показатель, аналогичный [[Z-оценка|Z-оценке]], используемый для оценки, на сколько стандартных отклонений отличается выборочное среднее $\overline{X}$ от среднего генеральной совокупности $\mu$, однако, в отличие от Z-преобразования, использующий выборочное стандартное отклонение $SD$ с учётом числа [[#Степени свободы|степеней свободы]] вместо среднеквадратического отклонения генеральной совокупности $\sigma$:
> 
> $$t = \frac{\overline{X} - \mu}{\frac{SD}{\sqrt{n}}}$$

## Пример

Производитель питьевой воды утверждает, что средняя концентрация свинца в его воде не превышает установленный норматив 15 ppb (частей на миллиард). Для проверки этого утверждения была взята случайная выборка из 10 бутылок воды и измерена концентрация свинца.

Были получены следующие выборочные данные (концентрация свинца в ppb):

$[15.5, 18.2, 17.0, 19.1, 14.8, 20.5, 16.3, 18.8, 17.5, 16.9]$

Вопрос: Можно ли на уровне значимости $α = 0.05$ утверждать, что средняя концентрация свинца в воде отличается от норматива?

Решение:

1. Сформулируем $H_{0}$:
    *   Средняя концентрация свинца равна нормативу 15 ppb ($\mu = 15$).

2. Рассчитаем $\bar{x}$, $s$:
    * $\bar{x} = 17.46$
    * $s \approx 1.793$

3. Рассчитаем $t$:
    * $t = \frac{17.46 - 15}{1.793 / \sqrt{10}} \approx 4.339$

4. Рассчитаем $df$:
    * $df = 10 - 1 = 9$

5. Найдём $p$:
    * Для $t$ при $df$ (двусторонний тест) p-значение равно примерно $0.0018$.

6. Сравним $p$ и $α$:
    *   $0.0018 < 0.05$

**Вывод:** средняя концентрация свинца в воде отличается от норматива 15 ppb на уровне значимости $\alpha$.

### Python

```python
import numpy as np
from scipy.stats import ttest_1samp, t

# Вводные данные

sample_data = np.array([15.5, 18.2, 17.0, 19.1, 14.8, 20.5, 16.3, 18.8, 17.5, 16.9])
n = len(sample_data)
mu = 15.0
alpha = 0.05


# Расчёт t-статистики и p-значения

sample_mean = np.mean(sample_data)
sample_std = np.std(sample_data, ddof=1)
t_stat, p_value = ttest_1samp(sample_data, mu, alternative="two-sided")


# Вывод

if p_value < alpha:
    print(
        f"P-значение ({p_value:.3f}) < α ({alpha}). "
        "Отвергаем нулевую гипотезу в пользу альтернативной."
    )
else:
    print(
        f"P-значение ({p_value:.3f}) ≥ α ({alpha}). "
        "Не отвергаем нулевую гипотезу."
    )


# Визуализация распределения t

x_values = np.linspace(-5, 5, 200)
dof = n - 1
probability_density = t.pdf(x_values, dof)
critical_t_stat = t.cdf(alpha, dof)

plt.figure(figsize=(8, 5), dpi=100)
plt.plot(
    x_values,
    probability_density,
    color="C7",
    label=f"Распределение t({dof})",
)
plt.axvline(critical_t_stat, color="C3", linestyle="--", label=f"Критическое значение t")
plt.axvline(t_stat, color="C4", linestyle="--", label=f"Рассчитанное значение t")
plt.fill_between(
    x_values,
    probability_density,
    where=(x_values <= -abs(t_stat)) | (x_values >= abs(t_stat)),
    color="C4",
    alpha=0.5,
    label="Вероятность",
)

plt.xlabel("t")
plt.ylabel("Плотность вероятности")
plt.title("t-критерий Стьюдента для 1 выборки")
plt.legend()
plt.show()
```
