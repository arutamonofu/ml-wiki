## Свойства

| Свойство                  | Значение                                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тип данных                | Количественный                                                                                                                                                                            |
| Количество выборок        | $2$                                                                                                                                                                                       |
| Тип связи между выборками | Связанные                                                                                                                                                                                 |
| Тип наблюдений в выборке  | Независимые                                                                                                                                                                               |
| Нулевая гипотеза          | Средние значения в генеральных совокупностях равны, или средняя разность между парными наблюдениями в генеральной совокупности ра                                                         |
| Распределение критерия    | [[Распределение Стьюдента]]                                                                                                                                                               |
| Условия                   | - Нормальное распределение разностей между парными наблюдениями, если размер выборки меньше 30.<br>- Отсутствие значительного количества выбросов в разностях между парными наблюдениями. |
| Обозначение               | $t$                                                                                                                                                                                       |

## Вычисление

$$\frac{\bar{d} - (\mu_1 - \mu_2)}{\frac{s_d}{\sqrt{n}}}$$
$\overline{d}$ — средняя разница между парными наблюдениями
$s_{d}$ — стандартное отклонение разниц между парными наблюдениями
$n$ — количество пар наблюдений

Степени свободы:

$$df = n - 1$$

## Пример

Исследователи хотят оценить эффективность нового препарата для снижения артериального давления. Они измерили систолическое давление у 15 пациентов до приёма препарата и через месяц после начала приёма. Были получены следующие данные по разностям давлений (до - после) для каждого пациента:

- Давление до приёма: $[147.6, 141.7, 144.1, 148.9, 147.7, 138.6, 143.3, 141.8, 145.2, 140.4, 140.8, 143.0, 141.1, 143.5, 145.5]$
- Давление после месяца приёма: $[135.8, 141.7, 139.3, 134.5, 135.7, 144.8, 140.1, 141.6, 138.2, 143.0, 142.6, 140.4, 142.3, 139.9, 137.9]$

Вопрос: оказывает ли препарат влияние на систолическое артериальное давление? Уровень значимости $\alpha = 0.05$.

Решение:

1. Сформулируем $H_{0}$:
	- Средняя разность давлений «до» и «после» в генеральной совокупности равна нулю.
2. Рассчитаем $d$:
	- $d = [11.8,0.0,4.8,14.4,12.0,−6.2,3.2,0.2,7.0,−2.6,−1.8,2.6,−1.2,3.6,7.6]$
3. Рассчитаем $\bar{d}$, $s_{d}$:
	- $\bar{d} \approx 3.693$
	- $s_{d}\approx 6.122$
4. Рассчитаем $t$:
	- $t = \frac{3.693}{\frac{6.122}{\sqrt{15}}} \approx 2.336$ 
5. Определим $df$:
	- $df = 15 - 1 = 14$
6. Найдём критическое значение $t$:
	- Для $\alpha$ при $df$ критическое значение $t$ примерно равно $2.145$. 
7. Сравним рассчитанное и критическое значения $t$:
	- $2.336 > 2.145$.

Вывод: на уровне значимости $\alpha$ средняя разность давлений «до» и «после» в генеральной совокупности отличается от нуля — препарат влияет на систолическое артериальное давление.

### Python

```python
import numpy as np
from scipy.stats import ttest_rel, t

# Вводные данные

pressure_before = np.array([147.6, 141.7, 144.1, 148.9, 147.7, 138.6, 143.3, 141.8, 145.2, 
                            140.4, 140.8, 143.0, 141.1, 143.5, 145.5])
pressure_after = np.array([135.8, 141.7, 139.3, 134.5, 135.7, 144.8, 140.1, 141.6, 138.2, 
                           143.0, 142.6, 140.4, 142.3, 139.9, 137.9])
alpha = 0.05


# Расчёт t-статистики и p-значения

t_stat, p_value = ttest_rel(pressure_before, pressure_after)


# Вывод

if p_value < alpha:
    print(
        f"P-значение ({p_value:.3f}) < α ({alpha}). "
        "Отвергаем нулевую гипотезу в пользу альтернативной."
    )
else:
    print(
        f"P-значение ({p_value:.3f}) ≥ α ({alpha}). "
        "Не отвергаем нулевую гипотезу."
    )


# Визуализация распределения t

x_values = np.linspace(-5, 5, 200)
dof = len(pressure_before) - 1 
probability_density = t.pdf(x_values, dof)
low_critical_t_stat = t.ppf(1 - alpha / 2, dof)
high_critical_t_stat = t.ppf(alpha / 2, dof)

plt.figure(figsize=(8, 5), dpi=100)
plt.plot(
    x_values,
    probability_density,
    color="C7",
    label=f"Распределение t({dof})",
)
plt.axvline(low_critical_t_stat, color="C3", linestyle="--", label=f"Критическое значение t")
plt.axvline(high_critical_t_stat, color="C3", linestyle="--")
plt.axvline(t_stat, color="C4", linestyle="--", label=f"Рассчитанное значение t")
plt.fill_between(
    x_values,
    probability_density,
    where=(x_values >= t_stat),
    color="C4",
    alpha=0.5,
    label="Вероятность",
)

plt.xlabel("t")
plt.ylabel("Плотность вероятности")
plt.title("t-критерий Стьюдента для 2 связанных выборок")
plt.legend()
plt.show()
```
